# 短剧生产工作流

从小说或剧本出发，逐步验证人物、场景、道具、分镜与图片生成的生产流程，并探索面向短剧工作者的应用产品。

当前处于资料整理与验证方案阶段。本仓库首批提供项目文档、问题台账和测试模板；尚无已验收的自动化生产结果或可运行 APP。

## 如何参与讨论

指出具体环节、输入条件、出现的问题与预期结果；有产物时附可分享的编号、截图或测试记录。候选方案、静态代码发现、实际运行结果和创作者验收分别记录。

有实际实现后再加入代码和运行说明，有真实测试后再加入测试结果。现有材料与外部项目的成果不计作本项目已完成的交付。

## 资料范围

首批不包含原始剧本全文、第三方资料包、安装程序、私人聊天记录或凭据。外部资料保留来源和版本，未整体复制进本仓库。公开剧本、参考图或成图前应先明确可分享范围；外部材料的许可适用其各自说明，本仓库未统一授予开源许可证。
