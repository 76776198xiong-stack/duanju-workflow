# 02 痛点与分析

来源：2026-11-13 口述整理。

## 朋友最苦恼的两件事

### 1. 复制粘贴提示词、反复新开对话

用的是 Gemini 网页版，步骤之间没有衔接。每产出一份文字，都要复制出来，新开对话，重新喂工作提示词，再贴进去。写、审、改都是 AI 在做，但每一次交接都要人来搬。

### 2. 在视频站里手动把图片和人物名称链接起来

资产图、分镜图、视频提示词要手动上传到视频站，然后在提示词里用富文本引用，把每个人物名称和对应的图片逐个链接起来。每个镜头都要做一遍。

## 其他问题

### 3. 提示词不够好，产出不稳定

没有控制好一集的文本量时，工作提示词产出的资产提示词会模糊、失效，最后图片素材效果差。分镜提示词同理。为了补救，他加了一道 AI 审查环节。

我们的分析：

- **审查环节是症状，不是解法。** 根源是工作提示词本身不够稳。目标是把工作提示词优化到不需要审查。
- **同一个 AI 审自己产出的东西，效果存疑。** 如果最后仍然需要审查，审查方必须是另一个模型，不能是产出方自己。
- **文本量失控和网页对话的用法有关。** 网页对话里每次贴多少、残留多少上文全凭手感。本地 Agent 可以把每一步的输入固定下来，每集用全新的上下文。

### 4. 没有一体化工作台

素材散落在多个对话和视频站里。同行已经有人在做一体化工作台，他也想要。

### 5. 分集和镜头数量没有明确规则

一集多少字、一集出多少镜头，目前没找到依据（见[现有工作流](01-现有工作流.md)末节）。这个量要和模型能力匹配：太少浪费时间，太多质量下滑。

### 6. 角色一致性和状态记录（推断，待验证）

- 角色跨镜头不变脸，靠文字描述大概率不够，需要把确认过的资产图作为参考图传给生图模型。
- 现在没有地方记录哪个资产出过图、采用哪一版、哪些镜头用了它。改设定后哪些要重做，只能靠人记。

### 7. 没有耗时数据

一集各环节花多少时间、返工几次，没有记录。做第一次测试时顺手记下来。
