# 05 新旧流程对比

状态：方案，尚未执行。

## 做法

用《萌娃心声》已经分好的第一集，新旧两套流程各做一遍，比到分镜图为止。视频暂时不比。

- **旧流程**：朋友现在的做法（Gemini 网页版，手动复制，人工审查）。如果第一集他已经做过，直接用现成结果，补记大概的耗时。
- **新流程**：本地 Agent 流水线，使用同一集剧本、同一套工作提示词。

两边尽量用同一个生图模型。如果做不到，结论里要写明：画面差异有一部分来自模型不同。

## 比什么

| 项目 | 怎么量 |
|---|---|
| 人工操作次数 | 复制粘贴、新开对话、上传文件各多少次 |
| 人工用时 | 人实际在操作的时间，不算等待生成 |
| 总用时 | 从拿到剧本到分镜图齐全 |
| 返工 | 每个资产、每个镜头重出了几次才采用 |
| 费用 | 能查到就记，查不到写"未知" |
| 画面质量 | 朋友逐张看图判断，见下表 |

## 看图判断

由朋友本人看，每张图给"采用 / 要改 / 不能用"，并写一句原因。

| 类别 | 看什么 |
|---|---|
| 人物资产图 | 像不像这个角色；年龄和体型对不对（本剧有萌娃和非人角色）；画风是否统一；多视图是不是同一个人 |
| 分镜图 | 动作和构图是否表达了剧情；角色跨镜头有没有变脸；场景和空间关系是否连贯 |
