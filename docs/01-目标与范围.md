# 目标与范围

更新日期：2026-11-13。

## 长期目标

将短剧生产中的重复工作逐项自动化，形成面向短剧工作者的应用。希望减少跨工具复制、重复提供设定、手工绑定参考素材和反复整理产物的劳动，并使角色、场景和道具跨镜头、跨集保持可追溯的一致性。

“全自动”是长期目标。覆盖到图片、分镜、视频还是最终成片，以及保留哪些创作确认点，尚未确定；当前不能据此承诺一键成片或零人工干预。

## 当前确定的首轮范围

以《萌娃心声》已经分好的第一集为输入，不重新分集。完成角色提取、人物资产提示词与图片，再生成分镜提示词与分镜图片，对比原 Gemini 工作流与 Codex 工作流的最终图片效果。

这是整套工作流对比，不要求使用相同生图模型，因此效果差异不能单独归因于提示词或文字模型。每次运行需记录实际模型、规则版本、参考图与修改过程。

首轮不制作视频、不处理整季，也不因资料中存在视频模板而扩大交付。

## 首轮应回答的问题

1. 人物与分镜图片是否达到创作者认可的质量，主要失败发生在哪一步？
2. 人物参考图是否实际传入后续生成，换状态、换装与跨镜后能否保持身份？
3. 人工操作、耗时、费用和返工主要集中在哪里，哪一段最值得先自动化？
4. 任务中断后能否从已确认版本继续，避免重做或混用资产？

## 待决定

- APP 的形态、运行环境和首个核心功能。
- 原工作流实际采用的提示词版本、模型与操作步骤。
- 本次画风、人物卡版式，以及逐镜出图还是按组拼图。
- 生成工具的真实接入方式、权限、成本和失败处理。
- 是否允许自动补充原文未说明的视觉设计，及其确认方式。
- 后续视频、声音、剪辑等环节的范围与顺序。

## 管理方式

先用一个真实任务验证具体问题，再决定是否扩大范围或纳入产品。建议以“输入、操作、判断、输出、失败、成本、验收”记录每个环节；这是一种推进建议，不是已完成实现。
