# 04 待确认问题

问清楚一条，就把答案写回对应文档，并从这里删掉。

## 现在卡在这里：材料和流程对不上

Codex 清点完了（见[材料索引](../references/材料索引.md)）。结论是朋友给的是一个资料库，不是一条流程：每一步都有多份互相矛盾的候选，有的步骤一份都没有。在朋友回答下面的问题之前，"按他现有的流程原样走一遍"没法执行。

| 步骤 | 材料里有什么 | 问题 |
|---|---|---|
| 资产工作提示词 | 三套：`manju-visual-director`、Midjourney Word、GitHub 仓库的 Skill | 互相矛盾。一套要保留皮肤纹理，一套要 3D 动画 CG 并禁止皮肤毛孔，一套是给 Midjourney 的英文提示词 |
| 分镜工作提示词 | `SD2.5分镜智能体 v2.1` | 它产出的是五栏镜头表（镜号、时长、景别、画面、对白），是给视频用的。没有找到"生成分镜图"用的工作提示词 |
| 视频工作提示词 | `五维镜头优化Skill`（即梦/Seedance 多镜一体化容器） | 有，但平台配置同时有 Seedance 2.0 和 SD2.5 两版 |
| 审查提示词 | 四份检查清单 | 没有找到他日常在 Gemini 里用的那份 |

**新发现**：朋友仓库的主技能来自开源套件 [drama-skills](../references/开源套件-drama-skills.md)，那里有现成的分镜、视频提示词、审查、生产技能。这可能改变第一次测试的做法，见下面"方向"一节。

**更好的解法**：请朋友屏幕共享，实际做一遍（哪怕只做一个人物加两三个镜头），从贴第一段提示词到在 Updream 里出视频。要自动化一个流程，得先亲眼看到它。口述、文档和实际操作三者可能不一样，以实际操作为准。

**次一级的解法**：请朋友把他最近做的某一集的 Gemini 对话，从第一步到最后一步，逐个用"分享链接"发过来（或者录屏）。那就是他真实的流程，比任何整理都准。

如果做不到，就请他逐条回答：

1. 资产提示词这一步，你现在往 Gemini 里贴的是哪份文件？
2. 分镜图是怎么来的？用什么提示词生成的？是一镜一张，还是一组镜头拼一张？
3. 分镜表（五栏镜头表）和视频提示词是什么关系？是先出镜头表，再转成视频提示词吗？
4. 审查用的那份提示词是哪个文件？不在压缩包里的话请单独发来。
5. 视频现在用 Seedance 2.0 还是 2.5？
6. 你的 `short-drama-image-prompts` 是从 drama-skills 拿来改的。套件里其他技能（分镜、视频提示词、审查）你用过吗？为什么只用了这一个？
7. 压缩包里哪些是你自己写的，哪些是从别人那里拿来参考的（比如带"0928"的两份 Word、打斗包、高武和校园模块）？

## 其他要问朋友的

5. 你的 GitHub 仓库是用本地 Agent 跑出来的（多个子代理、本地脚本），日常却是 Gemini 网页版手动操作。这两者是什么关系？那 215 张卡现在在用吗？
6. 第一集你自己做的资产图和分镜图能发来吗？用来和 Codex 的结果对比。
7. 在 Gemini 里用的是哪个模型（文字、生图）？生分镜图时会不会把资产图一起传进去作参考？
8. 文字和图片不在 Updream 里做，具体是哪里不行：贵、效果差，还是不好控制？
9. 在 Updream 里"把图片和人物名称链接起来"具体怎么操作？一个镜头要传几张图、链接几处？最好录一段屏。
10. "文本量没把控好"具体指什么：一次贴了多集、单集太长，还是对话太长后质量下降？
11. 分集有没有规则？一集多少字、出多少镜头，有没有测过？
12. 审查通常挑出什么问题？举三五个例子。
13. 一集从剧本到成片大概多久，时间主要花在哪？目前做完了多少集？
14. 你看中的同行工作台是哪个？

## 方向
