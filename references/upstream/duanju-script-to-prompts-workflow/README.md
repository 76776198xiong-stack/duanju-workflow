## 六步总览

```
docx 剧本 → ①切集 → ②资产盘点 → ③分波出卡（唯一真源）
         → ④登记合并（资产总表）→ ⑤三层校验 → ⑥一键派生交付
```

三条核心思想：**唯一真源**（只改剧集目录，其余脚本派生）、**一物一卡**（沿用不重出、变体引基准）、**一致性靠登记不靠记忆**。

## 硬规则速记

- 画风锁：每卡必带「必须是 3D 动画 CG，不得出现真人质感」＋负向前缀（真人/photorealistic/皮肤毛孔…）；渲染尾全剧逐字统一
- 人物卡十段 / 场景道具卡五段；四视图=同一 3D 模型旋转；变体卡必带【基准锁定】
- 保脸靠图生图（蒙版只涂衣不涂脸，重绘 0.3–0.45），**整张重画必换脸**
- 只换颜色不算改款；改基准服色要连带所有沿用制式的卡
