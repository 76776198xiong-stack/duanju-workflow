# tools 使用说明（换新项目怎么用）

四个脚本都**按自身位置定位项目根目录**（`ROOT = 脚本所在目录的上一级`），所以复用方法统一：

```bash
# 1) 把脚本复制进新项目的 项目开发/ 目录
cp tools/*.py 新项目/项目开发/

# 2) 改每个脚本顶部的这一行为新项目名（只影响输出标题/合集名）
PROJECT_NAME = '萌娃心声'   →   PROJECT_NAME = '新项目名'

# 3) 在项目根目录运行
python3 项目开发/重建汇总.py
python3 项目开发/导出可复制合集.py
python3 项目开发/生成预览.py
python3 项目开发/导出兼容版.py IMG-EPxxx-Cxx   # 单卡；--all 全量
```

## 各脚本职责与产物

| 脚本 | 读 | 写 | 说明 |
|---|---|---|---|
| 重建汇总.py | `剧集/EP*/图片提示词.md` | 索引.md、全剧资产总清单.md、全剧生成清单.xlsx、合集-去重版.md/.docx、合集分册/ | **改卡后必跑**；内置校验：缺渲染尾会拒绝生成 |
| 导出可复制合集.py | 同上 | 全剧提示词-可复制版.txt、可复制版/01–05.txt | 纯文本分段卡（`═` 分隔线、每段空行），用户日常框选复制用 |
| 生成预览.py | 同上 | 全剧提示词预览.html | 带搜索、分类筛选、一键复制的单文件网页；复制按钮在 file:// 下可能被剪贴板权限挡，主交付仍用可复制版 |
| 导出兼容版.py | 同上 | 出图兼容版/IMG-xxx.txt 与 *_精简.txt | 去星号去标签、正向/负向分开；精简版 511–1181 字，防出图工具字数超限报「输入内容有误」 |

## 约定与已知特例

- **`剧集/` 是唯一真源**，脚本只读它；派生件永远可以删掉重跑。
- `EP000` 特例：脚本把首出 EP000 的卡标成「原创补充／原创」——用于收原稿没有、用户点名新增的角色。新项目没有 EP000 目录就不受影响。
- 分类规则写死在脚本里：卡名含「Q版」→Q版形态；含「群像」或「对照板」→人物·群像；含「身份」→身份基准；其余 C 卡→状态变体；L→场景；P→道具。改命名约定时要同步改三个脚本（重建汇总／可复制合集／预览）的 `classify`。
- 生成预览.py 的 HTML 是深浅色自适应单文件，无外部依赖；卡片默认折叠、列表区限高内滚。
- 已在 60 个集目录、215 张卡的项目上全量空跑验证（2026-11）。
