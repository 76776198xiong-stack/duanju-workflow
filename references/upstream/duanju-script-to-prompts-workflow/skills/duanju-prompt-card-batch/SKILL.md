# 短剧图片提示词批次生产

按 EP001 样板为多集批量生产《图片提示词.md》并登记新资产：逐字对齐骨架、跨批次沿用对账、防编号冲突。

> 权威流程在 `short-drama-image-prompts` 技能里（它的 `references/series-batch-production.md` 波次配方、`scripts/qa_markdown_cards.py` 校验、`scripts/build_asset_aggregate.py` 去重汇总）。本技能只记本批实操口径；两边冲突时以上游技能为准。

## 流程
1. 先读三样：`剧集/EP001/图片提示词.md`（格式样板，逐字对齐）、`项目开发/资产总表.md`（一致性真源+首次登场矩阵）、各集剧本。
2. 不确定的资产先 `search_files` grep `剧集/EP002~EP0XX/图片提示词.md` 的 `^## IMG-` 行确认编号，不凭记忆沿用。
3. 每集结构：引言块（逐字沿用样板，仅改 EP 版本号）→ `## 本集资产清单（N 张卡）`四列表（编号/卡名/类型/用在哪些场，SC001…按剧本分 3–5 场）→ 表下沿用注释 + 本集不出卡注 → 新卡正文（`## IMG-EP0XX-CXX/LXX/PXX · 名称` + `- 参考：无外部参考` + `### 可复制提示词`）。
4. 沿用行：保留原编号、类型写 `T-XXX 沿用`、绝不重出正文；新变体卡的【基准锁定】引用首出编号。
5. 编号 C/L/P 各自从 01 递增（每集独立），每集总卡数 6–14（含沿用行）。

## 硬性格式项（自查）
- 16:9 4K；每卡 HEX ≥5 色；【图外标注】不进提示词正文。
- 人物卡右下角整句 `「AI演员声明：本角色为人工智能生成的虚构演员形象，仅用于影视项目角色设定与视觉开发，不对应任何现实人物。比例16：9」`；道具/场景卡不加声明。
- 每卡负向段尾逐字 `3D Chinese animation style，semi-realistic，high-end CG，studio lighting，soft film grain。`（全角逗号，句号收尾）。
- 需逐字可读的文字才写明（如「李宅」「和离书」「长命百岁」）；账册/懿旨正文一律只画密行、禁可读内容。

## 跨批次并发对账（关键坑）
- 另一批次可能在同时写相邻集；写前 grep 确认，若依赖卡不存在：自己在本批首集出卡（先写被依赖集），并在登记碎片写对账说明。
- 形态链卡（如洛洛婴儿态）用状态变体卡锚定最早身份基准（EP001-C01），并在登记碎片声明「若前批次满月卡先行登记，面部以其对齐、编号不并、不重出身份卡」。
- 矩阵已定首次登场集的人物（如范云裳 EP006）若在其首出集之后客串但卡未落盘：不出卡，写进「本集不出卡」注、走群像远景。
- 路人/台词提及者（太监、太后）不出身份卡。
- 剧本标题与正文不符时以正文为准（如「关门放狗」集正文无狗，不出狗卡）。

## 自查命令要点
用 Python 正则逐文件数：`^- 参考：无外部参考$`、`【负向提示词】`（引言句各多 1 属正常）、`soft film grain。`、`AI演员声明`、每卡 `#[0-9A-F]{6}`≥5；沿用行下方不得出现 `^## IMG-` 正文头。
