# 开源套件 drama-skills

2026-11-13 发现。朋友 GitHub 仓库里的主技能 `short-drama-image-prompts`，来自一个开源套件：

- 仓库：[zenstory-ai/drama-skills](https://github.com/zenstory-ai/drama-skills)
- 许可证：MIT
- 查看时的版本：0.11.2（提交 `8cf7404`，2026-11-10）
- 适用环境：Claude Code、Codex 及其他支持 Agent Skill 的本地 Agent

以下内容来自阅读它的 README 和各技能的说明，**没有安装或运行过**。

## 它有什么

套件一共 12 个技能，覆盖从原著到成片的整条链路。朋友的仓库只拿了其中 1 个。

| 技能 | 作用 | 朋友仓库里有吗 |
|---|---|---|
| `short-drama` | 项目初始化、阶段路由、**本地 Dashboard** | 没有 |
| `short-drama-novel-analyze` | 拆长篇小说，给出分集候选 | 没有 |
| `short-drama-develop` | 改编方案、分集地图 | 没有 |
| `short-drama-write` | 写或规范化单集剧本 | 没有 |
| `short-drama-assets` | 从剧本拆人物、场景、道具，写成 `视觉设定.md` | 没有 |
| `short-drama-image-prompts` | 资产图片提示词 | **有，且朋友做了改动** |
| `short-drama-storyboard` | 分镜，含"冻结关键帧提示词" | 没有 |
| `short-drama-video-prompts` | 把分镜和关键帧写成视频提示词 | 没有 |
| `short-drama-review` | 独立审查剧本、设定、图片/视频提示词、分镜 | 没有 |
| `short-drama-produce` | 确认后调用外部接口生成图片、视频、配音 | 没有 |
| `short-drama-edit` | 把镜头剪成成片，加字幕，统一响度 | 没有 |
| `short-drama-breakdown` | 拆解对标成片 | 没有 |

## 朋友对那一个技能做了什么改动

和原版逐文件比对：朋友的版本多了中文资产卡模板（十段人物卡）、整季批量生产的做法、几个检查和汇总脚本、自己的版本号 3.0.0 和更新记录，其余参考文件也都有修改。也就是说，他的仓库是"开源套件的一个技能 + 他自己的定制"。

## 和我们的关系

1. **我们缺的环节，这里都有现成的。** 朋友材料里找不到的"分镜图工作提示词"和"审查提示词"，在这个套件里分别是 `short-drama-storyboard` 和 `short-drama-review`。视频提示词、生产、剪辑也都有。
2. **它的思路和我们想做的基本一致。** 每个阶段一个 Skill，产物落成文件（`剧本.md`、`视觉设定.md`、`分镜.md`、`图片提示词.md`、`视频提示词.md`），审查由独立的技能做，带一个本地 Dashboard 看进度。
3. **它的生产技能里有 Seedance、火山引擎和 OpenAI 生图的适配。** 这意味着视频也许可以通过接口直接生成，不必经过 Updream 网页。成本是否比 Updream 划算，需要比较。
4. **有一处和我们的设想不同。** 它要求每次花钱生成前都由人确认；我们的设想是文字到出图全自动，人在图出来之后才审。这个可以调整。

## 作者的一段经验

README 里写：他们的漫剧工作室曾自建一体化图形工具，前后端近 8 万行代码，后来维护不动，改成"Agent 命令行 + 文件"，自建工具里只剩排队抽卡的功能。这和我们"工作台只做监控和审核，不做复杂"的方向是一致的。
